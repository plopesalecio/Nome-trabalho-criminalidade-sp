# Segurança Pública em São Paulo (2016–2025)

Projeto desenvolvido para a disciplina de Programação para Economistas da Universidade Presbiteriana Mackenzie.

Este trabalho tem como objetivo analisar a evolução dos principais índices criminais da cidade de São Paulo entre os anos de 2016 e 2025, utilizando técnicas de visualização de dados em Python para identificar tendências, padrões temporais e mudanças estruturais na dinâmica da criminalidade urbana.

## Indicadores analisados

- Homicídio Doloso
- Furto
- Roubo
- Furto e Roubo de Veículo
- Tentativa de Homicídio
- Lesão Corporal Dolosa
- Estupro

## Objetivos da análise

O projeto busca:

- Analisar a evolução temporal dos índices criminais
- Identificar impactos da pandemia de COVID-19 sobre a criminalidade
- Comparar o comportamento de crimes violentos e crimes patrimoniais
- Investigar padrões sazonais e variações mensais
- Avaliar variações percentuais anuais dos indicadores
- Desenvolver interpretações estatísticas e socioeconômicas a partir dos dados

## Visualizações desenvolvidas

O notebook contém diferentes tipos de visualizações estatísticas e analíticas, incluindo:

- Gráficos de linha
- Gráficos de barras
- Heatmaps
- Painéis analíticos
- Comparações percentuais anuais
- Indicadores proporcionais entre ocorrências

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
